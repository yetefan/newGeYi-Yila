## v2.9.15 功能回顾（2026-11-13）

这次新增五项聊天与管理功能，并修正主动搭话的表情标记时机。

### 1. 被动回复优先

有人 @伊菈或叫到名字时，同一会话中的主动评估会让位。未执行的主动任务会被移除；正在等待模型的评估会放弃发送旧结果，不再继续重试或切渠道。已经发出的HTTP请求无法撤回，仍可能产生调用费用。

### 2. 私聊10分钟连续对话

第一次叫名字并成功排进回复队列后，接下来可以直接聊天，不用每句话带名字。双方互动会刷新计时，**连续10分钟没有互动就关闭**，之后再次叫名字即可开启。原有防连发、每日额度、休眠和静默规则仍然生效。

### 3. 按话题调节主动搭话

近期已经参与过的相近话题会减少重复插话；群友接她的话或换到新话题时，适度提高参与机会。使用本地文字相似度判断，不额外调用模型。

### 4. 确认后修正记忆

先发「伊菈记忆」查看编号，再按下面的方式修正自己的事实记忆：

```text
伊菈修正记忆 2 正确的新内容
伊菈确认修正
```

会先展示旧内容和新内容，5分钟内确认才真正写入。也可以发送「伊菈取消修正」。只能修正自己的可见事实，不能改别人的记忆，印象和摘要暂不支持按编号修正。

### 5. 表情列表、预览与状态

骰主或主人可以使用：

```text
伊菈表情列表
伊菈预览表情 喝茶
伊菈表情包状态
```

可查看表情用途、缺图、开关、冷却、小时额度和近期回复节流原因。手动预览每会话15秒最多一张，不消耗自动表情额度。

### 本次修复与升级说明

- **主动搭话确认要发送正文时才贴QQ表情**；仅检查、选择沉默、调用失败、影子模式观察时不贴。被动回复仍在入队时贴表情表示收到。
- 修复表情回应复用语音HTTP地址时的动作路径、查询参数和口令处理。
- 132项相关离线测试通过。
- **更新后需要完整重载插件或重启OlivOS**，只发「重载设定」不会加载新的Python代码。
