## 这个版本加了什么

在原版 v2.9.11 的基础上：

- 发「伊菈菜单」，指令清单画成一张图，不再是一长段文字。画不出来时仍发原来的文字菜单。
- 「伊菈记忆」「伊菈状态」「伊菈用量」这类看一眼的报告也走同一套卡片。
- 记忆卡片标题下写明这份记忆属于谁；每条记忆下面一行小字标记录时间，这行只画在图上，不进对话记录。
- 卡片正文用思源黑体的粗体，发到群里不再发糊。
- 群里决定要回一条消息时（被点名，或自己主动搭话），先给那条消息贴一个 QQ 表情表示收到了。默认关，只对群聊生效。
- 渠道故障转移有了总时长上限：单个渠道卡住时不再把整轮超时冲破，超时后不再对同一个渠道重试。

原版从 v2.5 到 v2.9.11 的更新记录在 [CHANGELOG.md](CHANGELOG.md)，不在这里重复。

## 关于模型渠道

插件不绑定任何厂商：`config.json` 的 `providers` 填任意 OpenAI / Anthropic 兼容接口就能跑，
每家一个 `endpoint` + `api_key` + `model`，坏了会自动按 `priority` 往下切。
