# 确认式记忆纠错与表情预览

## 记忆纠错（普通用户可改自己的事实）

1. 发「伊菈记忆」查看自己的当前记忆页；沿用原来的半小时编号缓存。
2. 发「伊菈修正记忆 编号 新内容」，机器人回显旧内容、新内容。此时绝不写库。
3. 5分钟内发「伊菈确认修正」才执行更新；「伊菈取消修正」清除待确认操作。

待确认记录按发送者与完整会话键绑定，换人、换群、换私聊不可确认。只能处理当前会话按现有互通设置可见且属于自己的有效事实；印象、摘要不支持本命令。确认时重新检查归属、可见性和旧文本，并以参数化条件更新防止误覆盖；旧值变化、删除、过期均拒绝。更新保留事实归属和其他元数据，清掉旧关键词，失效当前编号页。新内容上限500字，不接受控制标记。待确认操作重启即消失。

## 表情（沿用现有立绘管理的骰主/主人权限）

- 「伊菈表情列表」：列名称和用途，标出缺图，附当前表情状态。
- 「伊菈预览表情 名称」：按renderer查图顺序发送实际图片；无效名称、缺图均给出提示。
- 「伊菈立绘状态」或「伊菈表情包状态」：继续复用renderer.emote_budget，显示开关、已加载/总数、缺图、冷却等待、小时上限和近期回复节流。

手动预览用于查素材，允许在自动表情关闭或冷却时查看；每个完整会话共享15秒冷却，避免多人刷图。预览不消耗自动表情额度。
